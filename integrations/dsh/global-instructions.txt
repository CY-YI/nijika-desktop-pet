Pending only means queued, never approved or confirmed visible. For a decision, repeat 45-second wait_for_reply calls on the same request ID when one wait returns pending, as the skill specifies; do not end the turn after one timeout. On any later turn with an unresolved Nijika request ID, read get_reply first, especially when the user says “继续” or “我回复了”. After an answered click, state the chosen option in this same DSH conversation before continuing. If the tools are unavailable, continue in chat without blocking the task.

虹夏桌宠｜解压后使用与 Agent 配置
适用：Windows 10/11，64 位。先解压整个压缩包，再打开里面的文件夹。
请保留完整 dist 文件夹。桌宠和审批程序各有同级依赖目录。

一、安装并启动
1. 打开同时包含 dist、distribution 的文件夹。
2. 在文件资源管理器顶部地址栏输入 powershell，按回车。
3. 复制下面这一整行到打开的窗口，按回车：

powershell -NoProfile -ExecutionPolicy Bypass -File ".\distribution\install.ps1"

安装后会启动角色，并在桌面创建“虹夏桌宠”快捷方式。双击图标打开设置中心。
以后双击这两个快捷方式即可。无需管理员权限；桌宠本体无需 Python。
默认安装位置：%LOCALAPPDATA%\NijikaDesktopPet\app

二、用 MAGPIE 接入你的 AI 客户端
1. 双击桌面“虹夏桌宠”，在“Agent 接入”页点击“添加 Agent”，或扫描本机后选择目标。
2. 点“检查 MAGPIE 分发”。未分发时查看步骤并复制配置提示词，发给能操作本机的 AI。已分发时可登记并查看验证步骤。
3. 在 MAGPIE Library 分发同一份 nijika-pet MCP 与 nijika-agent-dialog Skill；适用时分发每轮触发说明。
4. 重载目标客户端并新开任务，在桌面核对气泡和点击。重新打开向导可登记已检测到的分发。
   支持多个目标时可在 MAGPIE 一起勾选。已有路由先核对，避免叠加。每个宿主的原生审批和结束事件单独验证。

MCP 程序由客户端启动，不要手动双击。请保留 dist\虹夏MCP-v2 下的 EXE 和 _internal。
遇到 MAGPIE 不支持的目标，保留已工作的入口并查看 AGENT_SETUP.md。

三、做一次真实测试
在接入后的 AI 新任务里，复制发送：

请用虹夏的 request_decision 问我“先检查哪项？”。选项“界面”，说明“优先检查界面按钮”，标为推荐；选项“提醒”，说明“优先检查桌面提醒”。等待我在桌面点击，在本会话复述选择，再用 show_completion 发一条完成提醒。

验收：桌面出现选择气泡→点击后 AI 读回你的选择→随后收到完成提醒。
设置页的“发送测试提醒”只验证本机显示，不能代替上面的 AI 实测。
另开一个新任务，只问“1+1等于几”，不要提示使用虹夏。
已接结束事件的客户端应只出现一条提醒；主动通知后也应无重复。
各客户端独立验收，详见 nijika-notification-capabilities.json 与 NOTIFICATION_PROTOCOL.md。
在 VS Code 扩展中测试时，可在同一个新任务里补充：

调用虹夏 show_completion 时，请设置 task="VS Code 来源验证"，
summary="扩展真实连接测试"，agent_name="Codex"（或当前扩展名），software="VS Code"。

预期头部为“VS Code · Codex”等具体名称；若仍显示旧顺序，重载该扩展的虹夏 MCP 后新建任务。

四、日常使用
右键角色可打开设置或退出；外观、动作、互动与养成在设置中心调整。
导入新角色：进入“角色衣橱”，按页面教程导入 PNG 或多帧 ZIP。
开机自启：首次安装时，在第一部分安装命令的末尾加 -AutoStart。

五、没有气泡怎么办
先确认角色已启动，再到 Agent 卡片的“接入步骤”核对配置并测试提醒。
本机测试正常、AI 没反应：重载该客户端 MCP，在新任务重试第三部分。
任务已结束后才点击选择：回原 AI 会话说“继续”，让它读取此前回执。
命令授权气泡只是提醒，仍须在 AI 客户端原审批窗口批准。
Work/DSH 当前没有原生审批自动提醒桥接；MCP 注册不等于所有事件自动提醒。
VS Code 扩展扫描只能确认扩展文件已安装，不能证明扩展已启用或已经调用成功。
